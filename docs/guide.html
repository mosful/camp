整體流程

  1. 步驟 1～3：註冊帳號、建立 Repo、打開 Claude 你親手做照著畫面按按鈕，約 20 分鐘
  2. Prompt A：建立專案、認識範本 AI 做回答旅行名稱、日期等基本問題
  3. Prompt B：整理旅遊素材 AI 做把行程截圖丟給 AI，回答它的問題
  4. Prompt C：建立專案說明書 AI 做不用做任何決定
  5. Prompt D：做出網頁骨架 AI 做確認網站要有哪些區塊、喜不喜歡
  6. Prompt E：填入完整內容 AI 做行程、住宿、餐廳、導航、電話全部填好
  7. Prompt F：手機版檢查 AI 做自動檢查有沒有跑版
  8. Prompt G：上線 中間有一步你親手按拿到可以分享的網址 🎉

需要準備的東西

  • 一台可以上網的電腦（或手機、平板）：只要有瀏覽器就好，不用安裝任何軟體。第一次建議用電腦，螢幕大比較好操作。
  • Claude 付費方案（Pro 以上）：免費方案只能聊天，沒辦法讓 AI 幫你做網站。
  • GitHub 帳號：免費，用來放你的網站。
  • 旅遊資料：行程表、訂房確認、餐廳訂位、門票預約、分工名單⋯⋯截圖、LINE 文字都可以，不用整理，AI 會幫你整理。

這份教學怎麼用？

  • 每一段 Prompt（給 AI 的指令）都有 「複製」按鈕，按一下再到 Claude 貼上送出就好，不用看懂內容。
  • 可以 一段一段做（建議第一次這樣，比較好掌握進度），也可以用 一次全貼 的方式讓 AI 一路做下去。
  • AI 說話時看到 🛑，代表它停下來在等你回答或操作，照它說的做，回覆後它就會繼續。
  • 做到一半要離開也沒關係，每段完成 AI 都會自動存檔。下次回來看 疑難排解 的「對話中斷怎麼接續」。
⚠️ 隱私提醒：免費的 GitHub 網站是公開的，任何拿到網址的人都看得到，也可能被 Google 搜尋到。成員全名、小孩名字、個人手機號碼要不要放上去，AI 會在過程中問你，不確定就選「改暱稱」或「不放」。
步驟 1・你親手做

註冊 Claude 和 GitHub 帳號

⏱ 約 10 分鐘

1-1 註冊 Claude 並升級方案

  1. 打開 claude.ai，用 Email 或 Google 帳號註冊。
  2. 點左下角你的頭像 → 設定裡找到「方案」，升級為 Pro（或更高）。

1-2 註冊 GitHub

  1. 打開 github.com/signup 註冊。
  2. 使用者名稱（Username）會出現在網址裡。例如取 amy-travel，你的網站網址就會是 https://amy-travel.github.io/…。建議用簡短、全小寫英文、好唸的名字。
  3. 到信箱收驗證信，完成驗證。
步驟 2・你親手做

在 GitHub 建立網站專用的 Repo

⏱ 約 3 分鐘

Repo（倉庫）就是放你網站檔案的專案資料夾，放在 GitHub 上。

  1. 登入 GitHub 後，點右上角的 「＋」 → 「New repository」。（或直接打開 github.com/new）
  2. Repository name：輸入網站的英文代號，只能用小寫英文、數字、減號，例如 hualien-2026。
    它會變成網址的最後一段：https://你的帳號.github.io/hualien-2026/
  3. Description（說明）：可以留空，或寫「2026 花蓮旅遊手冊」。
  4. 選 Public（公開）。
    免費帳號只有 Public 才能做成網站。
  5. 勾選 「Add a README file」（如果看到「Add README」的開關，打開它）。
    這一步很重要：Repo 不能是完全空的，AI 才接得上。
  6. 其他選項都不用動，按最下面綠色的 「Create repository」。
建好後，把瀏覽器網址列的網址記下來（例如 https://github.com/amy-travel/hualien-2026），步驟 3 和 Prompt G 會用到。
步驟 3・你親手做

打開 Claude Code 網頁版，連上你的 Repo

⏱ 約 5 分鐘

Claude Code 是能「動手做事」的 AI：它在雲端的電腦上幫你寫網頁、存檔、上傳，你只要用瀏覽器跟它對話。

  1. 打開 claude.ai/code，用步驟 1 的 Claude 帳號登入。
  2. 第一次使用會請你 連結 GitHub：照畫面按「Connect GitHub」之類的按鈕，跳到 GitHub 後按 Authorize（授權）。
  3. 接著會請你 安裝 Claude 的 GitHub App，選擇要讓它存取哪些 Repo：
    • 建議選 「Only select repositories」，再選你在步驟 2 建立的 Repo（例如 hualien-2026）。
    • 按 Install（或 Save）。
    如果沒有自動跳出來，可以到 claude.ai/connect-github 設定。
  4. 回到 Claude Code 頁面，在 Repo 選單裡 選擇你的 Repo。環境（Environment）用預設的即可。
  5. 你會看到一個輸入框，就像聊天一樣。之後每一段 Prompt 都是貼在這裡送出。
💡 小提醒
  • 附加截圖：輸入框旁邊有迴紋針或「＋」圖示，或直接把圖片拖進輸入框。
  • AI 問你「允許嗎？」：這是安全確認，按允許即可。
  • 手機也可以操作：Claude 的手機 App 裡也有 Code 功能，操作方式一樣。
  • 每次開新對話都要選同一個 Repo，AI 才找得到你的網站。
Prompt A

建立專案、認識範本

⏱ 約 5 分鐘

AI 會讀範本、問你旅行的基本資料，並建立專案的基本檔案。

怎麼做
  1. 在 Claude Code 網頁版的對話框裡，按下面的「複製」按鈕，把 Prompt 貼上送出。
  2. AI 停下來問你問題（看到 🛑）時，照它說的回覆。
  3. 看到「Prompt A 完成」，就可以進行下一段。
💡 小提醒
  • 第一次貼上時，AI 可能會先問你「允許執行嗎？」之類的問題，按允許即可。
  • AI 問你旅行名稱、日期時，照編號一次回答，例如「1. 2026 花蓮三天兩夜 2. 3/20 早上 8 點～3/22 晚上 6 點 …」。
📋 Prompt
共通規則（每一段都適用，請先讀完）：
- 我是完全不會寫程式的新手。請全程用繁體中文（台灣用語）白話說明，少用專有名詞；一定要用的時候，用一句話解釋。
- 每做一件事之前，先用一句話告訴我「在做什麼、為什麼」。
- 需要我親手操作或做決定時，用「🛑 請你做：」開頭，把步驟寫清楚，然後停下來等我回覆，不要自己替我決定。
- 出錯時不要丟一大串英文錯誤訊息給我，先自己嘗試修正；真的需要我幫忙時，用白話說明發生什麼事。
- 如果這個 repo 已經有 CLAUDE.md，先讀它並遵守裡面所有規則。
- 範本是 https://github.com/mosful/camp 。需要參考時，把它 git clone 到 /tmp/camp-template（我的 repo 以外的暫存資料夾），只學它的版型與做法。範本裡的人名、電話、金額、店名、日期一律不准出現在我的 repo。
- 存檔方式：改完就 git commit（訊息用繁體中文），並且「直接推到 main，不要開 PR」。如果沒辦法推到 main，告訴我原因，並一步一步教我怎麼在 GitHub 網頁上按「Merge」合併。

【Prompt A：建立專案、認識範本】

請依序完成：

A. 確認環境
   1. 告訴我目前這個 repo 的名稱和我的 GitHub 帳號（從 git remote 查）。
   2. 把範本 clone 到 /tmp/camp-template。如果因為網路限制失敗，告訴我是哪個網址被擋，以及我要到哪裡的設定開放它，然後停下來等我。

B. 介紹範本
   讀範本的 README.md、CLAUDE.md、index.html，用 5～8 行白話介紹：這個範本網站有哪些區塊、有哪些好用的功能（例如一鍵導航、一鍵撥號、倒數計時、手機上表格自動變卡片、行前清單打勾）。
   並提醒我：範本裡有別人的真實個資，我們只學「版型和做法」，內容一律不照抄。

C. 🛑 問我以下問題（編號列出，讓我可以一次回答），然後停下來等我：
   1. 這趟旅行的名稱（例如「2026 花蓮三天兩夜」）
   2. 出發與結束的日期和大概時間（例如 3/20 早上 8 點出發、3/22 晚上 6 點結束）
   3. 地點（縣市或區域）
   4. 同行大約幾人？有沒有長輩或小孩？
   5. 網站想要什麼感覺或顏色（海邊藍綠、山林綠、溫暖橘、櫻花粉，或沿用範本）
   同時告訴我：網站完成後的網址會是 https://<我的GitHub帳號>.github.io/<repo名稱>/ （請代入實際的帳號和名稱）。

D. 我回答後，建立專案的基本結構：
   - sources/README.md：說明「這個資料夾放整理過的旅遊資料，網站內容以這裡為準」
   - .gitignore：每一行上面用繁體中文註解原因，至少包含：
       原始截圖與 PDF（*.jpg、*.jpeg、*.png、*.heic、*.pdf）→ 原因：可能含個資，repo 是公開的
       node_modules/、截圖/ → 原因：檢查用的工具檔，不屬於網站
   - README.md：改成我的旅行名稱、預計網址，以及一句話說明「這是用 Claude Code 製作的一頁式旅遊手冊」

E. git commit 並直接推到 main。
F. 回報「Prompt A 完成」，並列出：GitHub 帳號、repo 名稱、旅行名稱、日期、預計網址。

【Prompt B：整理旅遊素材】

我會在這則訊息附上截圖，或把文字貼在最下面。素材可能包含：行程表、訂房確認、餐廳訂位或點餐、門票與預約、交通與分工名單、行前注意事項。

請依序完成：

A. 盤點素材
   用表格列出你收到的每一份素材：編號／類型（截圖、文字…）／內容摘要（一行）。
   圖片請實際仔細閱讀，看不清楚的地方標記「⚠️ 看不清楚」。
   注意：不要把我傳的圖片存進 repo。

B. 整理成 sources/ 底下的 Markdown 檔（沒有該類資料就不要建立該檔）：
   - sources/01-行程總表.md      每天：日期、時間、活動、地點名稱
   - sources/02-住宿.md          名稱、地址、電話、入住/退房時間、房型、分房、費用
   - sources/03-餐食.md          每一餐：時間、餐廳、地址、電話、是否訂位、點餐明細、金額
   - sources/04-地點與導航.md    所有會去的地點：名稱、地址、電話、營業時間（一地點一列）
   - sources/05-交通與分工.md    誰開車、誰坐哪台車、誰負責什麼
   - sources/06-預約與票券.md    門票、體驗活動、訂金、聯絡窗口
   - sources/07-行前準備.md      要帶的東西、注意事項
   每個檔案最上面寫「資料來源：素材 #編號（對應 A 的表格）」。

C. 整理規則（非常重要，請嚴格遵守）：
   1. 只寫素材裡「真的有」的資訊。素材沒寫的不要自己補，也不要憑印象編地址或電話。
   2. 數字（金額、人數、時間）照抄原始值。同一件事在不同素材數字不一樣時，兩個都保留並標記「⚠️ 不一致」，不要自己選一邊。
   3. 有金額明細就幫我驗算合計；和素材上的總額不同時標記「⚠️ 合計不符」並列出算式。
   4. 同一個人在不同素材寫法不同時，標記「⚠️ 寫法不同」，不要自己統一。

D. 查證地點
   對 sources/04-地點與導航.md 的每個地點，上網查證地址和電話，標註「✅ 已查證（來源網址）」或「❓ 查不到」。
   素材上的地址和查到的不一樣時，兩個都列出並標記「⚠️」。

E. 🛑 一次把問題問完（編號列出），然後停下來等我回答：
   1. 所有「⚠️」和「❓」項目，逐一問我怎麼處理
   2. 一般旅遊手冊會有、但素材裡沒有的資訊（例如：集合時間地點、緊急聯絡人、住宿停車資訊、雨天備案）

F. 依我的回答更新 sources/，被我補充的地方註記「（依使用者口述補充）」。
   個資照我的決定處理後，才可以 git commit 並直接推到 main。

   git commit 並直接推到 main。

疑難排解

遇到狀況先看這裡，大部分都能直接把「解法」貼給 AI

Claude Code 裡找不到我的 Repo

通常是 Claude 的 GitHub App 沒有被允許存取這個 Repo。

  1. 打開 claude.ai/connect-github，重新連結 GitHub。
  2. 在 GitHub 的安裝設定裡，確認「Repository access」有勾選你的 Repo，按 Save。
  3. 回到 claude.ai/code 重新整理，再選一次。
AI 說「沒辦法下載範本」或「網路被擋」

雲端環境的網路權限比較嚴格。AI 會告訴你是哪個網址被擋。

  1. 在 Claude Code 對話上方的標題列找到雲端環境（Environment）的選單 → Edit（編輯）。
  2. 在「Network access」（網路存取）把被擋的網址加進允許清單，或改成較寬的存取等級。
  3. 存檔後跟 AI 說「我開好了，請再試一次」。

官方說明：Cloud environments – Network access

AI 開了「PR」，沒有直接更新網站

PR（合併請求）就像「修改提案」，要按一下同意才會生效。兩種處理方式：

  • 直接跟 AI 說：「請直接推到 main，不要開 PR」。
  • 自己按：打開 AI 給你的 PR 連結 → 往下捲找到綠色的 Merge pull request → 再按 Confirm merge。
網址打開是 404（找不到頁面）
  • GitHub Pages 剛開啟需要 1～2 分鐘，等一下再重新整理。
  • 確認 Prompt G 的「開啟 GitHub Pages」步驟有做，而且 Branch 選的是 main、資料夾是 / (root)。
  • 確認網址拼字：https://帳號.github.io/repo名稱/，全部小寫。
手機打開還是舊的內容

手機瀏覽器會暫存舊網頁。在網址後面加上 ?v=2（每次換個數字）重新打開，或把分頁關掉重開。
